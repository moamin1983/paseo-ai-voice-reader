AI Voice Reader narrates assistant responses and provider-published reasoning in the native Paseo interface. A Reading plan speaker appears in workspace headers and a Voice On/Off pill appears beside each agent composer. The header expands full spoken text and the exact current queue. Optional native timeline rows show full message text, expandable exposed thinking, spoken previews and message controls. The compact reading plan has a live show/hide switch; hidden controls restore the original Paseo message UI without restarting the agent or resetting narration. The reader panel has Play, Pause, Resume, Stop, Skip, Replay, and inclusive start/end message selection.

Automatic narration reads newly completed sentences without replaying earlier streamed output. All agents share one playback queue on each connected client. Audio plays through Paseo on that client, including when the daemon is remote. Exposed reasoning is optional; hidden model reasoning is never available.

Requires Paseo 0.11.4 and Python on the daemon machine. Edge Neural uses Microsoft cloud TTS and needs explicit consent in Voice settings. Offline Kokoro uses sherpa-onnx CPU inference with local Kokoro model files. Run the documented manual Python setup, then configure the absolute Python executable, plugin worker and local model paths in settings. Activation does not download packages or weights. The tested offline model is English v0.19.

The master switch is off initially. Choose a backend, enable the master switch, then press Voice On for the narration target on this client. Settings include voice, speed, current-target/all-agent scope, assistant/reasoning filters, and optional code, JSON, log text, and sensitive-text inclusion. Settings are shared by clients of the same host. Automatic playback arming is client-local and resets on reload.

Cloud TTS sends readable narration text to Microsoft. There are separate consent controls for exposed reasoning and code/sensitive text. Filters are best-effort and cannot recognize every secret or source-code fragment; use offline Kokoro for confidential material. There is no silent backend fallback. Tool-call timeline rows are excluded.

Paseo 0.11.4 exposes file playback without a pause/cancel handle, so Pause, Stop, and Skip take effect at sentence boundaries. Current-target scope follows the agent selected in this plugin or its composer pill; the SDK does not expose an active-composer focus event. The plugin renders assistant, sent-message and exposed-thinking text rows through the supported timeline API to add inline range actions. Source matches that are ambiguous or outside loaded history can be selected in the dedicated plan. Sent messages stay excluded unless enabled in content filters. Only retained, completed timeline messages can be selected. Provider coverage depends on compatible published events.
