# Security reports

Report suspected security or privacy issues privately to **m.t.amin1983@gmail.com**. Include the affected version, reproduction steps using synthetic data, and the expected/actual behavior.

Do not post real agent transcripts, API credentials, private reasoning text, native settings dumps or sensitive generated audio in public issues. Redact personal and environment-specific details.

Plugins run as trusted code on the daemon and client. Review source and dependency changes before installing. Cloud TTS consent, offline processing boundaries, filtering behavior, RPC validation and stale playback handling are security-relevant parts of this project.

No response-time or support-service guarantee is implied.
